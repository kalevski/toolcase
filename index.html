// how it's built

One image. Everything it needs is inside.

The Next.js app, node:sqlite with WAL and FTS5, whisper.cpp and ffmpeg all ship in a single container. A single in-process worker claims jobs one at a time, transcodes to 16kHz mono, runs whisper-cli, and indexes the result — no external database, no message queue, no GPU driver to install.

Deliberately small, deliberately inspectable, deliberately yours.

[01]
Audio never leaves your infrastructure
whisper.cpp runs inside your own container. Nothing is ever sent to a third-party transcription API.
[02]
Someone else's data 404s, never 403s
A resource you don't own doesn't appear to exist at all — not even as a permission error. Admins are the only exception.
[03]
Crash-safe by construction
A job stuck mid-transcription when the process dies goes back to pending on restart. Orphaned files are swept daily.
[04]
Boring SQLite persistence
One file, WAL mode, full-text search built in. No external database, no message broker, no moving parts to babysit.
[05]
Budget-conscious by design
No large model tier, worker concurrency capped at 1 — tuned to run reliably on a machine you already own, not a GPU box.

// get started

One container. You're the admin.

Sign in happens over GitHub OAuth — there's no local password to set up. The first person to sign in becomes admin; everyone after lands as a standard user, or as a guest if you've configured an allow-list. Role changes apply on the very next request — no re-login needed.

Everything durable — the SQLite file, uploaded media, downloaded models, notes — lives under one bind-mounted /workspace volume. Back it up with cp.

# pull and run
docker pull ghcr.io/kalevski/toolcase/voxscribe:latest
docker run -d --restart unless-stopped \
--name voxscribe \
-p 4200:4200 \
-v "$HOME/voxscribe-workspace:/workspace" \
--memory 5g \
-e VOXSCRIBE_GITHUB_CLIENT_ID="<github-oauth-client-id>" \
-e VOXSCRIBE_GITHUB_CLIENT_SECRET="<github-oauth-client-secret>" \
-e VOXSCRIBE_AUTH_SECRET="$(openssl rand -hex 32)" \
-e VOXSCRIBE_OAUTH_REDIRECT_URI="https://your-domain/api/auth/github/callback" \
ghcr.io/kalevski/toolcase/voxscribe:latest
# open voxscribe, sign in with GitHub — you're the admin
