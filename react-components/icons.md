# Icon Candidates

Unified list of game genres and development terms that can feasibly be drawn as a single SVG glyph. Each entry lists a suggested visual.

---

# Genres

## Action & Combat
- Action                       — crossed swords / burst
- Action-Adventure             — sword + compass
- Adventure                    — backpack or compass + map
- Platformer                   — character leaping between platforms
- Puzzle-Platformer            — puzzle piece on a platform
- Metroidvania                 — interconnected room map
- Beat 'em up                  — fist with impact lines
- Hack and Slash               — slashing sword arc
- Fighting                     — boxing gloves
- Stealth                      — hooded figure / footprint in shadow
- Bullet Hell                  — dense bullet pattern
- Shoot 'em up (Shmup)         — top-down ship with bullet stream

## Shooters
- Shooter                      — crosshair + pistol
- First-Person Shooter (FPS)   — gun barrel from first-person
- Third-Person Shooter (TPS)   — over-the-shoulder figure + gun
- Tactical Shooter             — helmet + rifle
- Hero Shooter                 — masked hero silhouette
- Extraction Shooter           — helicopter + loot bag
- Battle Royale                — shrinking circle + last player

## Role-Playing
- Role-Playing Game (RPG)      — sword + shield
- Action RPG                   — dynamic sword swing
- JRPG                         — stylized hero sprite
- Tactical RPG                 — grid + pawn
- MMORPG                       — globe with multiple characters
- Souls-like                   — bonfire
- Dungeon Crawler              — arched dungeon doorway
- Roguelike                    — skull + die
- Roguelite                    — die + checkpoint flag

## Strategy
- Strategy                     — chess knight
- Real-Time Strategy (RTS)     — base + marching units
- Turn-Based Strategy (TBS)    — hourglass + pawn
- 4X Strategy                  — compass + planted flag
- Grand Strategy               — globe + flag
- Tower Defense                — tower with arrow arc
- MOBA                         — three-lane map
- Auto Battler                 — gear + pawn

## Simulation & Management
- Simulation                   — gears / dials
- Immersive Sim                — branching arrows
- Life Simulation              — house + family silhouettes
- Vehicle Simulation           — steering wheel
- Flight Simulation            — airplane + yoke
- Farming Simulation           — tractor / wheat stalk
- Dating Sim                   — heart + chat bubble
- City Building                — cityscape silhouette
- Construction and Management  — crane + scaffolded building
- Tycoon                       — coin stack + building
- Economic Simulation          — rising graph + coin

## Survival, Horror & Open World
- Open World                   — horizon / globe
- Sandbox                      — bucket + block
- Exploration                  — compass
- Survival                     — tent + campfire
- Survival Crafting            — crossed tools / anvil
- Horror                       — ghost silhouette
- Survival Horror              — bloody blade on tent

## Puzzle & Thinking
- Puzzle                       — interlocking puzzle piece
- Physics-Based                — bouncing ball arc
- Trivia                       — question mark + lightbulb
- Word Game                    — letter tiles

## Cards & Board
- Card Game                    — playing card
- Collectible Card Game (CCG)  — fanned card stack
- Deck-Building                — card deck + up arrow
- Board Game                   — board grid + pawn

## Casual & Arcade
- Arcade                       — arcade cabinet / joystick
- Casual                       — smiling face
- Hyper-Casual                 — tapping finger
- Endless Runner               — running figure with motion trail
- Idle / Incremental           — clock + coin
- Clicker                      — cursor clicking
- Party                        — balloons / confetti
- Social Deduction             — half-mask

## Sports, Racing & Rhythm
- Sports                       — ball + whistle
- Racing                       — checkered flag
- Fitness                      — dumbbell / heart-pulse
- Rhythm                       — musical note + directional arrow
- Music                        — musical note

## Narrative
- Visual Novel                 — speech bubble + book
- Interactive Fiction          — open book with branches
- Text-Based                   — terminal prompt ">"
- Walking Simulator            — footprints
- Narrative                    — open book

## Creative & Educational
- Creative                     — palette + brush
- Educational                  — graduation cap
- Programming                  — code brackets / terminal

# Development Terms

## Engine
- navmesh                      — blue polygon grid over terrain
- collision detection          — two boxes touching with impact
- physics engine               — falling box with motion arrow
- playtesting                  — gamepad + magnifying glass
- procedural generation        — generated maze / noise terrain
- chunk loading                — streaming world tiles
- level streaming              — world blocks flowing in

## Design
- hitbox                       — box outline around character
- hurtbox                      — red box outline
- aggro                        — angry-eye / exclamation over enemy
- kiting                       — character running while shooting back
- grinding                     — XP bar filling
- respawn                      — character re-emerging from circle
- spawn point                  — portal marker / pin
- spawn camping                — tent + crosshair over portal
- camping                      — tent with crosshair
- frag                         — skull or grenade
- gank                         — converging ambush arrows
- nerf                         — downward arrow / scale tipping down
- buff                         — upward arrow / flexing bicep
- cooldown                     — radial timer / clock
- DPS                          — sword + damage counter
- AOE                          — filled circle with radius
- DOT                          — dripping poison droplet
- HOT                          — green cross / healing drop
- proc                         — sparkle burst
- mob                          — generic monster silhouette
- NPC                          — person with speech bubble
- hit scan                     — straight beam / laser line
- projectile weapon            — arrow or bullet in flight
- aim assist                   — crosshair with magnet
- checkpoint                   — waypoint flag
- questline                    — scroll with branching path
- skill tree                   — branching node tree
- loot table                   — chest + item list
- drop rate                    — items falling + percentage
- endgame                      — crown / trophy
- season pass                  — ticket
- battle pass                  — tiered badge / ticket
- microtransactions            — coin + cart
- loot box                     — wrapped mystery box
- gacha                        — capsule-toy machine
- daily quest                  — calendar with checkmark
- weekly reset                 — calendar with circular arrow
- telegraphing                 — ground warning zone
- hitstop                      — pause icon + impact burst
- screen shake                 — wobbling frame
- dead zone                    — analog stick with center circle
- combo system                 — "x5" counter
- frame data                   — filmstrip / frame ruler
- invincibility frames         — character with star-glow
- hit stun                     — stars circling head
- block stun                   — shield with stop bar
- permadeath                   — skull + padlock
- save scumming                — save icon + reload arrow

## Networking
- matchmaking                  — two player icons connecting
- ELO                          — ranked badge with number
- MMR                          — ladder rung with number
- ranked queue                 — ladder / tier list
- unranked                     — empty rank slot
- lobby                        — waiting-room with player dots
- input lag                    — controller + delay arrow

## Graphics
- ragdoll                      — floppy body
- clipping                     — body intersecting wall
- noclip                       — translucent ghost through wall
- LOD                          — near high-poly / far low-poly model
- culling                      — camera frustum with hidden objects
- texture atlas                — grid of packed textures
- lightmap                     — pre-baked light pattern on surface
- baked lighting               — light + lock icon on surface
- sprite sheet                 — grid of animation frames
- tilemap                      — square-tile grid
- parallax scrolling           — layered scrolling backgrounds
- FPS (frames per second)      — frame counter / graph
